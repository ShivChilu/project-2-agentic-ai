# Policy POL-011: Programming Languages and Software Engineering Practices

- **Document ID:** POL-011
- **Document Title:** Programming Languages, Systems Programming, and Applied Software
- **Category:** Software Engineering
- **Policy Clause:** CLAUSE-PROG-11.1
- **Description:** Standard programming textbooks covering foundational computer science curricula (such as Python, Java, C++, and Data Structures) qualify for rapid acquisition provided there is active high student demand (Score >= 70.0), no redundant duplicate copies in stock, and sufficient available remaining budget.
